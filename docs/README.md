## מפת תיקיות קצרה

| תיקייה | מה יש בה? | למה צריך אותה? |
| --- | --- | --- |
| `app/` | דפי האתר ונתיבי API | כשמוסיפים מסך או פעולה בשרת |
| `components/racing/` | טפסים, עורך, רכז, ניווט | כשמשנים מסך או חוויית שימוש |
| `components/ui/` | כפתורים, טבלאות ורכיבים משותפים | רכיבי ממשק חוזרים |
| `lib/` | לוגיקה, הרשאות, תרגום, ייצוא | כשההתנהגות של המערכת משתנה |
| `data/` | הגדרות שדות ומיפויים לטפסים הרשמיים | כשרוצים לשנות שאלות או מיפוי |
| `supabase/` | מיגרציות ופונקציית אחסון בענן | עבודה על הנתונים וההרשאות |
| `public/` | לוגו ונכסים ציבוריים | קבצים המוצגים באתר |
| `tests/` | בדיקות אוטומטיות | לוודא שלא נשברה פונקציונליות |
| `scripts/` | פקודות הכנה ותחזוקה | ליצירת קטלוג ולהכנת תבניות |
| `docs/` | כל מדריכי הצוות | להדרכה ולתיעוד |
| `.github/` | בדיקות CI, תבניות PR ו־Issues | ניהול עבודת הפיתוח |

יש גם תיקיות **תאימות היסטוריות** (`db/`, `drizzle/`, `worker/`) וקובצי הגדרות בשורש. לא מוחקים או מעבירים אותן רק משום שהן לא נראות קשורות ל־Next.js; הן עשויות לשמש בדיקות, תיעוד או שחזור. [הפירוט המלא](architecture.md).

## מה לא מעבירים ל־GitHub?

סיסמאות, מפתחות, קובצי `.env.local`, תשובות אמיתיות של חברי הצוות, מסמכים פנימיים וגיבויי מסד. האתר הפעיל והנתונים שלו נמצאים ב־Vercel ו־Supabase בהתאמה — לא בקובצי הקוד.

## לפני שינוי בטופס רשמי

שינוי מזהה שדה, מיפוי לתא Excel או גרסת תבנית עלול לפגוע בתשובות קיימות ובייצוא. פתחו שינוי בענף נפרד, תעדו את ההשפעה ובדקו ייצוא. גרסאות ESF/ASES/SES שבקוד אינן מאשרות כשלעצמן התאמה לעונת FS Italy 2027.
